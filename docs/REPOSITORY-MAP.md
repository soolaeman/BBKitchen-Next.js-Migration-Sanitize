## Public Redirect / Canonical Reference

GitHub does not provide a generic HTTP redirect from one repository to another unless the repository itself is renamed.

Therefore public repositories should use an explicit canonical-reference notice/link rather than pretending they are technical redirects.

Canonical portfolio destination:
https://github.com/soolaeman/BBKitchen-Next.js-Migration-Sanitize

Routing rule:
- Portfolio / sanitized engineering reference → BBKitchen-Next.js-Migration-Sanitize
- Active frontend implementation → Front-End-BBKitchen
- AI Growth + Apps Script layer → BBK-AI-Growth-Automation
- Private automation runtime → BBK-Automation

## Security Boundary

Never move these into a public repository:
- credentials
- API keys
- tokens
- Telegram sessions
- private infrastructure identifiers
- customer data
- private business data
- internal operational credentials
- production-only configuration
